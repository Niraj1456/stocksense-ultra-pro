# LOGIC PHILOSOPHY

Every calculation in this system follows three laws:

## LAW 1 — DETERMINISM
Given the same input data, the system always produces the same output. No randomness. No ambiguity. Every formula is explicit. Every threshold is defined. Every edge case has a handler.

## LAW 2 — TRACEABILITY
Every score, signal, and verdict can be traced back to the exact data point that produced it. No black boxes. No unexplained outputs. Every number shows its work.

## LAW 3 — HIERARCHY
Not all signals are equal. The system enforces a strict hierarchy: Veto → Environment → Forensic → Institutional → Technical → Predictive → Fundamental. Higher hierarchy signals override lower ones when they conflict.
